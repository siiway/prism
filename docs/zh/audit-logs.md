# 审核日志（Transparent Control）

> 本文档由 AI 撰写并经过人工审核。

Prism 会将与安全相关的操作记录到一个只追加的审核日志中，并按三个作用域拆分。每个作用域仅对相应的负责人可见，并各自拥有实时 Webhook。

| 作用域                           | 可查看者                                | 记录内容                                                       |
| -------------------------------- | --------------------------------------- | -------------------------------------------------------------- |
| **Transparent User Control**     | 用户本人，以及站点管理员                | 自己的登录、授权、撤销和账号变更，以及自己拥有的应用的授权事件 |
| **Transparent Team Control**     | 团队所有者 / 共同所有者，以及站点管理员 | 团队中的所有编辑与成员变动，以及团队所拥有应用的授权事件       |
| **Transparent Platform Control** | 平台管理员                              | 任何管理员操作                                                 |

## 在哪里查看

- **用户** — 仪表盘 → **通知 → 审核日志**。
- **团队** — 团队页面 → **审核日志**标签页。
- **平台** — 管理面板 → **审核日志**。
- **以管理员身份查看任意用户** — 管理 → 用户 → 管理 → **审计**。

站点管理员可以读取每一个作用域。当管理员对某个团队或账号执行操作时，记录会写入*该*作用域的日志，并标记 `site_admin: true`，使受影响的用户能看到做了什么。

## 导出

每个作用域都可以导出为 CSV 或 JSON，筛选条件与当前表格相同：`GET /api/audit/<scope>/export?format=csv|json`。导出上限为 10,000 条事件。

## 每条事件记录的内容

- **时间** — 事件发生的时间。
- **操作用户** — 执行操作的用户。悬停可查看其 ID。
- **操作** — 稳定的操作标识，如 `user.login` 或 `team.member.add`。
- **资源** — 受影响的对象，按名称展示。悬停可查看类型与 ID。
- **请求 IP** — 仅展示前缀；悬停可查看完整地址。
- **客户端** — 客户端类型；悬停可查看完整 User-Agent。
- **查看详情** — 打开该事件的完整信息，包括原始元数据。

## 筛选

每个审核面板都有**时间区间**筛选和**操作**筛选。点击任意行中的操作用户、操作或资源即可设置对应筛选。**清除筛选**可重置全部筛选。

## Webhook

每个面板都有一个**编辑 Webhook**按钮，点击进入 Webhook 管理页。Webhook 会将该作用域的事件实时推送到外部目标。每个 Webhook 都有一个**事件**字段：以逗号分隔的操作名称列表，或用 `*` 表示该作用域下的所有事件。

### Discord

填入 **Webhook URL**。事件以 embed 卡片形式发送。

### Telegram

填入 **Bot Token**，可选填 **Chat ID** 和 **Thread ID**。消息以格式化 HTML 发送。

### 通用 Webhook

填入 **URL**、**方法**（`GET` 或 `POST`）、**请求头**（JSON 对象）和**请求体**（用于 `POST`）。任意部分都可以包含以下占位符：

| 占位符            | 值                  |
| ----------------- | ------------------- |
| `{id}`            | 事件 ID             |
| `{action}`        | 操作标识            |
| `{actor_id}`      | 操作用户 ID         |
| `{actor_name}`    | 操作用户的显示名称  |
| `{resource_type}` | 资源类型            |
| `{resource_id}`   | 资源 ID             |
| `{resource_name}` | 资源名称            |
| `{ip}`            | 完整请求 IP         |
| `{user_agent}`    | 完整请求 User-Agent |
| `{timestamp}`     | Unix 时间戳         |
| `{metadata}`      | JSON 编码的元数据   |
| `{summary}`       | 一行摘要            |

## 从旧 Webhook 系统迁移

旧的实例与用户 Webhook 已被本系统取代。管理员可在**管理 → 维护 → 危险区域 → 迁移旧版 Webhook**中导入它们；每个旧 Webhook 会在对应作用域中变为一个通用 Webhook。该操作可安全地多次运行。
